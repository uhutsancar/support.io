📝 How to use this demo:

Step 1: Make sure your backend server is running on http://localhost:5000

Step 2: Create a site in the admin panel and copy your site key

Step 3: Replace YOUR-SITE-KEY-HERE in this HTML file with your actual site key

Step 4: Click the chat bubble in the bottom-right corner to start chatting!
